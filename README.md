Taller de Bicicletas

Evaluacion Parcial 1 - Programacion Orientada a Objetos (DSY1102)

Programa en Java que registra bicicletas electricas y de montaña de un taller,
calcula el costo de mantencion de cada una y permite buscarlas por codigo.

Como ejecutarlo

Abrir el proyecto en IntelliJ IDEA y ejecutar la clase Main que esta en la carpeta src.
